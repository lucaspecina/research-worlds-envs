Turno 5

Razonamiento

REASONING: We now have solid evidence that at speed 1.0 the mean is about 5.8 and variance is close to the mean, supporting a Poisson-like count model. The remaining issue is the shape of the speed effect: the means at 0.8, 1.0, 1.1, 1.2 are strongly convex, and simple log-linear or power-law fits miss the 1.0 and 1.1 points badly. A low-parameter interpolation that exactly honors the observed means and remains smooth over [0.8,1.2] is more credible than forcing a wrong parametric form. I’ll fit a cubic polynomial to the experimental mean-vs-speed points and submit a Poisson model with λ(s)=max(eps, cubic(s)); this matches the apparent Poisson dispersion and should generalize reasonably within the bounded range.

Código

import numpy as np

speeds = np.array([0.8, 1.0, 1.1, 1.2], dtype=float)
means = np.array([
    exp_lo["y"].mean(),
    exp_10["y"].mean(),
    exp_mid["y"].mean(),
    exp_hi["y"].mean()
], dtype=float)

coef = np.polyfit(speeds, means, 3)
print("cubic coefficients:", coef)
grid = np.array([0.8, 0.9, 1.0, 1.05, 1.1, 1.15, 1.2])
pred = np.polyval(coef, grid)
print("grid predictions:", dict(zip(grid, pred)))

code = f"""
import numpy as np
import pandas as pd

_COEF = np.array({coef.tolist()}, dtype=float)

def model(regime, n, seed):
    rng = np.random.default_rng(seed)
    speed = float(regime.config.get("speed", 1.0))
    lam = float(np.polyval(_COEF, speed))
    lam = max(1e-6, lam)
    y = rng.poisson(lam=lam, size=n)
    return pd.DataFrame({{
        "unit_id": np.arange(n, dtype=int),
        "y": y.astype(int)
    }})
"""
res = env.submit(code)
print("accepted:", res.accepted)
print("error:", getattr(res, "error", None))

import numpy as np
import pandas as pd

_COEF = np.array([-846.1805555554813, 2618.229166666429, -2640.5902777775304, 874.3499999999157], dtype=float)

def model(regime, n, seed):
    rng = np.random.default_rng(seed)
    speed = float(regime.config.get("speed", 1.0))
    lam = float(np.polyval(_COEF, speed))
    lam = max(1e-6, lam)
    y = rng.poisson(lam=lam, size=n)
    return pd.DataFrame({
        "unit_id": np.arange(n, dtype=int),
        "y": y.astype(int)
    })
