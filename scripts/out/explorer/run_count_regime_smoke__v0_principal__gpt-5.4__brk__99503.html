Razonamiento

REASONING: The added runs strongly support a discontinuity or very sharp threshold around speed 1.08: means near 1.03–1.07 stay around 5.5–7, while 1.08+ jumps to roughly 11–14. Since variance remains close to mean on both sides, a piecewise Poisson model is the most defensible surrogate. With no budget left, the best move is to submit a simple thresholded mean function, using a mild linear trend below and above the jump calibrated from the observed means.

Código

code = r'''
import numpy as np
import pandas as pd

def model(regime, n, seed):
    rng = np.random.default_rng(seed)
    speed = float(regime.config.get("speed", 1.0))
    
    # Piecewise Poisson rate with threshold near 1.08 inferred from experiments.
    if speed < 1.08:
        # Fit from low-speed observations: around 4.46 at 0.8 and ~5.75 at 1.03
        lam = 4.46 + 4.3 * (speed - 0.8)
    else:
        # High-speed regime: around 12.25 at 1.08 and ~13.99 at 1.2
        lam = 12.25 + 14.5 * (speed - 1.08)
    
    lam = max(0.1, lam)
    y = rng.poisson(lam, size=n)
    return pd.DataFrame({
        "unit_id": np.arange(n, dtype=int),
        "y": y.astype(int)
    })
'''
