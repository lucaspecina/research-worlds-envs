    We parameterize Beta(alpha, beta) where mean = base*speed / N.
    Choose alpha, beta such that variance of p matches desired dispersion.
    Let total concentration s = alpha+beta, then Var(p) = mu*(1-mu)/(s+1).
    We can set s such that overall variance matches observed overall variance/mean ratio.
    For simplicity, fix s to a constant (to be calibrated).
    """
