Razonamiento

Reasoning:
Within-lot measurements can differ, but often they are similar (sometimes identical). This suggests that each measurement is an independent draw from the same latent defect rate for that lot, not a fixed count. So the lot has a random defect rate λ, and each measurement is Poisson(λ) (or NB) conditional on λ. That would produce correlation within lot. If λ is gamma-distributed across lots, then marginally each measurement is NB with correlation within lot.

Thus our model should:
- Draw a latent defect rate λ for each lot from a gamma distribution with shape r and scale θ (so mean = rθ, variance = rθ²).
- For each of repeats_per_unit measurements, draw y ~ Poisson(λ).
- Then marginally, each y is NB with mean μ = rθ and variance μ + μ²/r, and within-lot correlation = 1/(r+1) (for Poisson-gamma).

Now we need to see how speed affects the gamma parameters. Let μ(speed) = r(speed) * θ(speed). We have marginal mean estimates at three speeds. We also have within-lot correlation information: we can estimate r from the within-lot variance if we have repeats. From the small experiment, we can compute empirical within-lot variance and between-lot variance to estimate r.

But first, let's estimate r using moment matching on the lot-level latent λ? Actually we can't observe λ. However, with repeats_per_unit=2, we can compute the intraclass correlation (ICC) for NB-Poisson hierarchy. For a Poisson-gamma model, the correlation between two measurements of same lot is ρ = λ variance / (λ variance + λ mean) = (rθ²)/(rθ² + rθ) = θ/(1+θ). And θ = μ/r. So ρ = (μ/r)/(1+μ/r) = μ/(μ+r). Rearranging, r = μ(1-ρ)/ρ.

We can estimate ρ from the repeats data: compute pairwise correlation within lot. Let's do that quickly with the small dataset.

# But we can estimate r via: r = μ^2 / (between_var * (repeats) - μ) ??? Let's derive later.
# Instead, compute empirical correlation ρ_hat = (between_var - avg_within_var/2) / (between_var + avg_within_var/2)?? Not exact.
# Let's compute ICC directly using ANOVA formula
df = df_repeats
ss_total = ((df['y'] - df['y'].mean())**2).sum()
ss_between = ((lot_means - df['y'].mean())**2 * 2).sum()  # 2 repeats per lot
ss_within = ss_total - ss_between
ms_between = ss_between / (n_groups - 1)
ms_within = ss_within / (len(df) - n_groups)
icc = (ms_between - ms_within) / (ms_between + (2-1)*ms_within)  # ICC(2,1) for two measurements
print("ICC estimate:", icc)
print("Average within-lot variance:", avg_within_var)
print("Variance of lot means:", between_var)
print("Overall mean:", df['y'].mean())

# Now estimate r from ICC and overall mean μ
mu = df['y'].mean()
if icc > 0:
    r_est = mu * (1 - icc) / icc
    print("Estimated r from ICC:", r_est)
else:
    print("ICC zero or negative")

import numpy as np
import pandas as pd

def model(regime, n, seed):
    np.random.seed(seed)
    speed = regime.config.get("speed", 1.0)
    repeats = regime.config.get("repeats_per_unit", 1)
    
    # Power-law parameters from final fit (using all four points)
    log_mu_coeff = (1.887, 0.889)   # b0, b1
    log_r_coeff = (0.905, -0.843)   # a0, a1
    
    mu = np.exp(log_mu_coeff[0] + log_mu_coeff[1] * np.log(speed))
    r = np.exp(log_r_coeff[0] + log_r_coeff[1] * np.log(speed))
    theta = mu / r  # scale parameter of gamma
    
    # Number of lots needed
    n_lots = int(np.ceil(n / repeats))
    # Draw lambda for each lot
    lambdas = np.random.gamma(shape=r, scale=theta, size=n_lots)

            unit_ids.append(float(i))
        measurement_count += reps
        if measurement_count >= n:
            break
    
    df = pd.DataFrame({'unit_id': unit_ids, 'y': y_list})
    return df
