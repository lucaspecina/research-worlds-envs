Turno 3

Razonamiento

REASONING: Repeats are clearly not identical re-measurements; they are fresh count outcomes within a lot, and total variance comes from both within-lot Poisson-like noise and between-lot heterogeneity. The near equality of within-unit variance and between-unit mean hints at a Gamma-Poisson hierarchy: for each lot draw a latent rate λ, then repeated measurements are Poisson(λ). Under that model marginally y is negative binomial, and corr among repeats is driven by Var(λ). The speed effect on the mean is substantial and looks close to multiplicative, so with our remaining budget it's reasonable to fit a simple power law mean(speed)=μ0*speed^β using the archive plus these experiments, estimate the NB/Gamma-Poisson dispersion from all data, and submit. I'll compute method-of-moments estimates and immediately build the model.

Código

import numpy as np
import pandas as pd

# Reconstruct/collect data from previous cells
hist = df.copy()
hist["speed"] = 1.0
hist["source"] = "archivo"

for _name, _df, _speed in [("exp_lo", exp_lo, 0.8), ("exp_md", exp_md, 1.0), ("exp_hi", exp_hi, 1.2)]:
    _df["speed"] = _speed
    _df["source"] = _name

all_df = pd.concat([hist, exp_lo, exp_md, exp_hi], ignore_index=True)

# Speed -> mean fit: log E[y] = a + b log(speed)
speed_means = all_df.groupby("speed")["y"].mean().reset_index()
x = np.log(speed_means["speed"].values)
ylog = np.log(speed_means["y"].values)
b, a = np.polyfit(x, ylog, 1)  # ylog = b*x + a
mu0 = float(np.exp(a))
beta = float(b)

# Dispersion estimate from grouped repeats: lambda ~ Gamma(shape=k, scale=theta), y|lambda ~ Pois(lambda)
# Then Corr(repeats)=Var(lambda)/(E[lambda]+Var(lambda)); and marginal Var(y)=mu + mu^2/k.
# Estimate k from all rows via method of moments around speed-adjusted means.
mu_i = mu0 * (all_df["speed"].values ** beta)
vy = np.var(all_df["y"].values - mu_i, ddof=1) + np.var(mu_i, ddof=1)  # rough total variance check
# Better: use Pearson-like moment for NB2, solving E[(Y-mu)^2 - mu] ≈ mu^2/k
num = np.sum(mu_i**2)
den = np.sum((all_df["y"].values - mu_i)**2 - mu_i)
k = float(num / den) if den > 0 else 1e6
k = max(k, 1e-6)

print("speed means:")
print(speed_means)
print("\nFitted mu(speed)=mu0*speed^beta with mu0=", mu0, "beta=", beta)
print("Estimated Gamma shape k=", k)

code = f'''
import numpy as np
import pandas as pd

MU0 = {mu0!r}
BETA = {beta!r}
K = {k!r}

def model(regime, n, seed):
    rng = np.random.default_rng(seed)
    speed = float(regime.config.get("speed", 1.0))
    R = int(regime.config.get("repeats_per_unit", 1))
    R = max(1, R)
    n_units = (n + R - 1) // R

    mu = MU0 * (speed ** BETA)

    # Gamma-Poisson hierarchy: per-unit latent rate lambda, repeated rows conditional Poisson(lambda)
    shape = K
    scale = mu / shape
    lam = rng.gamma(shape=shape, scale=scale, size=n_units)

    unit_ids = np.repeat(np.arange(n_units), R)[:n]
    y = rng.poisson(np.repeat(lam, R)[:n])

    return pd.DataFrame({{"unit_id": unit_ids.astype(float), "y": y.astype(float)}})
'''
res = env.submit(code)
print("accepted:", res.accepted)
print("error:", getattr(res, "error", None))
