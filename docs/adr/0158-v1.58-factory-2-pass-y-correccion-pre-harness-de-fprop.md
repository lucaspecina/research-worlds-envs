## Corrección encontrada antes del harness

La ficha llamaba “reapertura incoherente” a cualquier caso con
`G_own < ε_prop`, aunque la mejora todavía superara el costo y pagar fuera racional. Eso
confundía estabilidad de una razón con racionalidad de la decisión.

Desde `factory.3`:

- `ε_prop = 5%` del rango de utilidades de la instancia sobre la grilla;
- si `G_own < ε_prop`, F_prop queda **bajo resolución** y no se estima;
- solo es **reapertura incoherente** si además `G_own ≤ costo_reapertura`;
- el robot “cambiar un poco” usa el mismo umbral por instancia, no la constante provisional
  20.

La corrección no altera verdad, evidencia ni posterior, pero sí una clasificación. Por eso se
versiona como `stratified-diagnostic-panel-r8-metricfix-v2`, se deriva otra cohorte fresca del
nuevo identificador y se la congela antes de abrirla. El commit de esta ADR será el sello.

## Auditoría de frontera público/privado antes de montar el episodio

Una revisión independiente dio NO-GO al viejo `public/manifest.json` como entrada del agente,
aunque no tuviera campos secretos directos: mezclaba el balance experimental del investigador
con el prior normativo, omitía las ecuaciones necesarias para reconstruir el posterior y la
API de escritura devolvía por accidente el reporte privado completo.

Antes del harness se corrige así:

- `agent_recipe.json`: solo prior, soporte, ecuaciones completas de media/ruido/activación,
  leyes de las tres continuaciones y utilidad; sin cohorte, hashes, commits, gates ni seeds;
- `researcher_manifest.json`: cohorte y diseño balanceado, explícitamente no agent-facing;
- `factory_certification.json`: verdad, seeds y oráculos, privado;
- `write_factory_report()` ya no devuelve el reporte privado: retorna solo estado agregado y
  rutas; el harness usará `build_agent_recipe(target_line=...)`, que ni acepta una familia;
- tests recursivos impiden que claves de cohorte/verdad aparezcan en la receta del agente.

El soporte normativo sigue teniendo solo dos tripletas. Se acepta **solo para el episodio de
cableado** y queda como bloqueo explícito antes de corridas conductuales: todavía no satisface
el claim de que parámetros continuos evitan resolver la tarea como un menú superficial.
