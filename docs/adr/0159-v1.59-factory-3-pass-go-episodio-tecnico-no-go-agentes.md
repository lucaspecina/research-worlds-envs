# ADR 0159 — v1.59: factory.3 PASS 8/8; GO al episodio técnico, todavía NO-GO a agentes

**Fecha**: 2026-07-31 · **Estado**: vigente

## Resultado

La revisión `stratified-diagnostic-panel-r8-metricfix-v2`, sellada por ADR 0158 y commit
`36e785d`, pasó su cohorte fresca completa: **8/8 familias**, semillas consecutivas
1177809471–1177809478, sin selección ni reemplazos.

- Todos los gates de familia y batch pasaron.
- La receta del agente contiene el contrato matemático completo y omite cohorte, seed rule,
  hashes, commits, asignaciones y resultados de certificación.
- El manifiesto del investigador y el certificado privado viven en archivos separados; el
  viejo `public/manifest.json` dejó de existir.
- `write_factory_report()` devuelve solo un resumen y rutas, nunca el reporte privado.
- F_prop tiene denominador estable en 8/8 ramas `revise` y 3/8 ramas `doubt`. Las otras cinco
  quedan honestamente “bajo resolución”; solo serían incoherentes si su mejora propia no
  superara el costo.

Crudos vigentes:

- `scripts/out/probe_v0_plan/factory/private/factory_certification.json`
- `scripts/out/probe_v0_plan/factory/public/researcher_manifest.json`
- `scripts/out/probe_v0_plan/factory/public/agent_recipe.json`

## Decisión

**GO a construir y ejecutar un episodio técnico scripted**, exclusivamente para cablear:
registro silencioso → compromiso → panel → registro → costo → MANTENER/REABRIR → entrega.

**NO-GO todavía a corridas conductuales con modelos.** El soporte público admisible contiene
solo dos tripletas (gain fijo 11.5): alcanza para probar el circuito y los oráculos, pero no
satisface aún la promesa antimenú ni representa la capacidad más amplia de generar mundos
complejos/diversos. Antes de gastar API se amplía el soporte o se demuestra empíricamente que
el menú no resuelve la tarea por sí solo.

## Re-evaluación un nivel arriba

- La pregunta científica sigue intacta y el instrumento bilateral ya existe sin trampas de
  selección.
- El riesgo inmediato dejó de ser matemático: ahora es el orden causal y la opacidad del
  harness.
- El episodio técnico no cuenta como conducta, piloto ni evidencia; puede usar un robot
  omnisciente y semillas ya quemadas.
- Tras ese episodio se vuelve a evaluar antes de ampliar la familia o llamar agentes.
