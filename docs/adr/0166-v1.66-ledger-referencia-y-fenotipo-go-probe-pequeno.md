# ADR 0166 — Ledger, referencia y fenotipo pasan; GO a probe pequeño

**Fecha:** 2026-08-01  
**Estado:** vigente — autoriza tres donantes DeepSeek; exige gate superior posterior

## Decisión

La elegibilidad general de ADR 0165 se conserva para estudiar formación, pero el slice de
sobre-generalización agrega un gate específico: `M_pre` debe contener una forma incremental
compartida entre líneas, medido solo desde el propio artefacto. Un modelo válido que no contiene
esa creencia no puede informar su revisión.

El servidor persiste ahora todas las vistas de datos realmente entregadas; el actualizador v0 se
reconstruye desde ese ledger y sigue llamándose referencia legal, no posterior único. La corrida
prospectiva DeepSeek 93001 pasó fenotipo, replay, ledger, referencia y entrega en ambos polos.

Se autoriza únicamente el probe de tres donantes de la ficha
`2026-08-01-ficha-probe-pequeno-overgen-v0.md`. Sus ramas son apareadas y la unidad estadística
es el donante. Al terminar se revisa un nivel arriba antes de SOTA o escala.

## Por qué

La revisión retrospectiva descubrió que DeepSeek 92000 tenía artefacto válido pero no la creencia
objetivo, mientras gpt 91001 sí. Sin el fenotipo habríamos atribuido resistencia a una creencia
inexistente. El nuevo gate resuelve ese error sin mirar verdad ni seleccionar por performance.
