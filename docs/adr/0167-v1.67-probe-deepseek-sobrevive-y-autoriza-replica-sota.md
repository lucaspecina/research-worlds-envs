# ADR 0167 — Probe DeepSeek sobrevive; autoriza una réplica SOTA

**Fecha:** 2026-08-01
**Estado:** vigente — una corrida gpt-5.4 y luego gate superior

La tanda válida 94100–94102 pasó integridad 3/3. Dos donantes con `M_pre` ancho acabaron bien en
ambos gemelos; el donante con `M_pre` estrecho y competente empeoró al revisar tanto cuando debía
cambiar parcialmente como cuando debía conservar. Es una señal mecanística interesante, no una
estimación de frecuencia.

La auditoría obligó a reemplazar el actualizador reconstruido por uno prior-preserving. El cambio
se aplicó solo al análisis derivado, deja crudos intactos y corrige una falla normativa real: una
referencia de mantener no puede ser peor que mantener el propio modelo.

Se autoriza únicamente gpt-5.4 semilla 94200 bajo el contrato correspondiente. Después se detiene
la ejecución y se revisa si este slice merece piloto multi-modelo.
