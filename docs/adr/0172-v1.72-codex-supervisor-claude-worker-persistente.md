# ADR 0172 — Codex supervisor científico + Claude worker persistente

- **Versión:** v1.72
- **Fecha:** 2026-08-02
- **Estado:** Vigente
- **Decisor:** Lucas

## Decisión

Codex pasa a conducir el ciclo de investigación cotidiano como **supervisor científico y de
estrategia**: mantiene el mapa completo, audita el anfitrión, decide entre mantener/modificar/
pivotear/abandonar y revisa directamente la evidencia. Claude Code funciona como **worker
persistente y contrapunto intelectual**: implementa, ejecuta, investiga subtareas, autopsia y debate,
pero no absorbe la decisión de rumbo. Lucas conserva la autoridad final.

Se crea una sesión Claude exclusiva para este vínculo, separada de la sesión interactiva de Lucas.
Todas las llamadas usan Claude Fable 5 con esfuerzo máximo; Opus 5 con esfuerzo máximo es la única
alternativa autorizada. No hay fallback automático a otros modelos.

## Persistencia y enforcement

- `AGENTS.md` fija el rol de Codex y se carga en sus sesiones.
- `CLAUDE.md` fija el rol de Claude y se carga en las suyas.
- `docs/operativa-codex-claude.md` es la fuente única del protocolo compartido.
- `scripts/claude_worker.ps1` reanuda siempre la misma sesión e inyecta un recordatorio breve en
  cada turno; el identificador local queda en `scratch/claude-worker-session.json`.
- Cada tres tareas, y tras compactación/pivote/sorpresa, se hace un refresco completo de rol.
- Tras una señal válida solo se admite un control decisivo adicional en el mismo anfitrión, salvo
  excepción explícita vinculada al claim.

## Relación con ADR 0116

Este ADR **supersede únicamente la organización operativa** de ADR 0116 (“Codex como segunda
opinión, no escritor de código”). Se conserva su razón de independencia crítica, pero la dirección
se invierte: Codex supervisa y Claude ejecuta. Codex puede hacer inspecciones y cambios mínimos de
coordinación, pero la construcción sustantiva se delega al worker.

## Razón

El proyecto documentó repetidamente la regla de volver un nivel arriba y aun así encadenó controles
locales sobre mundos que ya sabía pequeños. Un recordatorio blando no alcanzó. Separar supervisión
de ejecución, más una condición de salida dura por anfitrión, reduce el riesgo de que el detalle de
implementación capture la dirección científica. Claude sigue aportando tanto capacidad de ejecución
como desacuerdo productivo; Codex debe comprobarlo contra crudos y no aceptar consensos por autoridad.
